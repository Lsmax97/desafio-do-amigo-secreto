Sorteio do Amigo Secreto

Este projeto é  simples para organizar o jogo de Amigo Secreto. Ele permite  adicionar nomes de participantes, e raliza o sorteio e  de forma fácil e interativa.

## Funcionalidades

Adicionar Participantes
- Insira o nome de cada participante no campo de texto e clique em "Adicionar".
- O nome será validado para garantir que não está vazio e que não é repetido.

 Sortear
- Quando houver pelo menos 2 participantes, o botão "Sortear Amigo Secreto" estará disponível.
- Clique nele para sortear aleatoriamente um amigo secreto.

Design Simples e Interativo
- O design da aplicação é simples e oferece uma boa experiência ao usuário, com feedbacks como alertas para adicionar mais participantes ou evitar nomes duplicados.

 Tecnologias Utilizadas

- **HTML**: Estrutura da página.
- **CSS**: Estilos básicos (opcional, pode ser adicionado conforme a necessidade).
- **JavaScript**: Lógica de adicionar participantes, sortear e limpar a lista, além de validações.
